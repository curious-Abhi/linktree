# Curious Abhi: Linktree

Animated link page built with Next.js 14 (App Router), TypeScript, Tailwind CSS and Framer Motion.

## Run it

```bash
npm install
npm run dev      # http://localhost:3000
npm run build && npm start
```

## Customise

- Photo: put your picture at `public/mypic.png` (an initial shows until you do).
- Name, roles and every link: edit `src/data/links.ts`.
- Colors and animations: `tailwind.config.ts` and `src/app/globals.css`.

## Deploy

Push to GitHub and import the repo on Vercel or Netlify. No extra settings needed.
